“Surprise 库（协同过滤）+ Neo4j（图谱过滤）” 的混合模式

第一阶段：环境准备与底层数据准备
提示 Cursor：

请在后端环境中安装 scikit-surprise 库。

在 models.py（或 app.py 的模型部分）中确保有 LearningHistory 表，必须包含字段：user_id, resource_id, action_type（VIEW, STAR, DOWNLOAD）。

编写一个工具函数 get_rating_matrix()，将用户的行为转换为评分：VIEW=1分，STAR=3分，DOWNLOAD=5分。返回一个 Pandas DataFrame。

第二阶段：实现推荐算法引擎
提示 Cursor：
在后端创建一个 recommend_service.py（或在 app.py 中直接添加）：

使用 surprise.SVD 算法。

编写 train_model() 函数：读取评分矩阵，训练模型并保存。

编写 get_cf_recommendations(user_id, top_n=10)：利用训练好的模型，预测该用户对未交互资源的评分，返回初步候选清单。

第三阶段：结合 Neo4j 进行图谱重排序（核心亮点）
提示 Cursor：
编写一个函数 refine_with_kg(user_id, candidate_list)：

连接 Neo4j，查询该用户近期点击过的资源的知识点标签。

获取这些知识点在图谱中的后继知识点（Next_to）或相似知识点（Related_to）。

检查候选清单中的资源：

如果资源属于“后继知识点”，权重乘以 1.5（进阶推荐）。

如果资源属于“已掌握知识点”，权重乘以 0.5（避免重复）。

返回最终排序后的前 5 个资源。

第四阶段：开发 API 接口与触发逻辑
提示 Cursor：

在 Flask 中创建接口 GET /api/resources/recommend。

触发逻辑：

接口应根据当前登录用户的 id 实时计算。

增加一个 POST /api/action 接口，每当用户执行收藏或下载时，调用此接口记录行为，并标记“推荐列表需要更新”。

确保返回的数据结构与前端 ResourceCard 组件兼容（包含标题、封面、知识点标签等）。

第五阶段：前端界面集成
提示 Cursor：

修改 LearningView.vue 或 HomeView.vue，增加“智能推荐”模块。

使用 onMounted 钩子调用推荐接口。

实时反馈：监听收藏按钮的点击事件，一旦成功，局部刷新（Reload）推荐列表组件，体现即时推送效果。

💡 给你的技术小贴士（防止 Cursor 翻车）：
数据冷启动处理：告诉 Cursor：“如果用户是新用户，没有任何行为数据，请直接返回当前全系统下载量最高的 5 个资源作为兜底。”

性能优化：由于 SVD 训练较慢，可以让 Cursor 实现“每隔 1 小时后台训练一次，查询时直接取训练好的模型结果”。
